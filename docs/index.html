Academic simulation, not investment advice. Rules were fixed before the run (config hash shown above). Card prices are GUIDE prices (TCGplayer market price), not completed sales; ASKING ≠ SOLD ≠ GUIDE ≠ DERIVED. Free data has no completed-sale feed, so exit values are estimates. Card data is thin and smoothed, equity data is exchange-grade. A few months is one market regime, so nothing here proves either asset class is better.
